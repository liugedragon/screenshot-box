# 英文示例图片

简体中文 · [English](../samples/en/README.md)

这些虚构资料用于英文页面的界面截图，包含彩色课程表、购物订单、保修信息、代码笔记、旅行清单和家居物品表。文字与图形为原创，按项目 [MIT 许可证](../../LICENSE)提供。

在[英文示例目录](../samples/en/README.md)下载 PNG，然后在截图资料盒中选择“导入”，或拖入资料库。状态变为“可搜索”后，可查询 `SB-20260926-001`、`B204` 或 `queue`；这些词来自图片文字。

界面截图中的标题、备注、标签和星标为示例分类，导入 PNG 不会自动添加这些信息。[识别记录](../images/en/sample-ocr.json)包含一次本地 CPU 识别的文字、原图行框、置信信息和模型版本。
