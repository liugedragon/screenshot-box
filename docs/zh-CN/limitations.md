# 已知限制

简体中文 · [English](../limitations.md)

ScreenshotBox 当前为测试版。已有检查结果见[测试记录](validation.md)。

## 功能

- 应用提供英文和简体中文界面，跟随系统模式在启动时读取 Windows 显示语言。修改语言需重启；系统错误和 Windows 文件对话框可能仍使用操作系统语言。其他显示语言包尚未进行实机测试。

- 搜索使用关键词字面包含匹配，不提供语义检索；大规模资料库性能尚未测量。
- OCR 使用中英文移动模型。低分辨率、手写、复杂背景和倾斜文字可能识别不准。高亮范围为整行文字框。
- 标注暂不支持文字、实色遮盖或保存后重新编辑。马赛克不保证安全脱敏；在截图会话中擦除马赛克会恢复原图。
- 回收站支持删除和恢复，暂不支持永久清空。备份包含回收站资料。
- 不提供资料加密、应用数字签名、自动更新、云同步或账户系统。

## 体积与运行

0.1.4 安装包约 84.0 MiB，ZIP 约 108.5 MiB。包内包含 .NET 运行时、中文 OCR 模型、ONNX 和相关原生库。

OCR 模型按需加载，首次识别有加载延迟。0.1.1 单机观测中，空资料库启动 6 秒后工作集约 148.3 MiB；多窗口识别测试约 360.3 MiB，空闲 90 秒释放模型后约 281.1 MiB。日常占用随图片数量、打开窗口和模型状态变化。

关闭主窗口后应用继续在托盘运行。完全退出需使用托盘菜单。卸载保留资料库，用户可自行删除不再需要的数据。

## 未验证的场景

目前硬件检查使用一块 2560 × 1440 显示器，125% 缩放。以下场景尚未完成实机验证：

- 真实 Windows 登出再登录，以及任务管理器的启动启用、禁用操作。
- 双屏、混合 DPI、跨屏鼠标选区及外接屏拔插。
- 常见外部应用粘贴、完整人工键鼠流程及长期连续使用。
- 物理断网且未安装开发 SDK 的新 Windows 电脑。
- 更多系统缩放比例和显示器布局。
- 设置中目录迁移、备份恢复与重启的完整人工流程。

发行程序已验证使用随包运行时；中文 OCR、恢复到新目录和剪贴板读回有程序化测试覆盖。
