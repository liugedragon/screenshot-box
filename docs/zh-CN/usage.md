# 使用说明

简体中文 · [English](../usage.md)

## 安装与设置

运行安装包并选择安装目录，或解压完整 ZIP 后运行 `ScreenshotBox.exe`。首次启动建立本地资料库。

安装目录和资料目录分开。在设置中选择“更改保存位置并迁移资料”，可以迁移图片、识别文字和分类。目标目录非空时，应用创建专用子目录。迁移完成后自动重启，原目录保留。

设置支持系统、浅色和深色主题。语言默认跟随 Windows 界面语言：中文系统使用简体中文，其他系统使用 English。可选择“跟随系统”“简体中文”或“English”，切换后重启生效。界面语言不改变 OCR 模型，中文和英文内容仍由随包提供的模型识别。

## 截图

1. 按 `Ctrl+Alt+S`，拖动框选。
2. 松开后拖动八个调整点改变大小，在“选区”模式拖动内部可以移动选区。
3. 需要时添加画笔、箭头、矩形、橡皮擦或马赛克。
4. 按 `Enter` 或点击“保存并复制”。图片保存到资料库并复制到剪贴板，随后返回原来的应用。

“仅复制”不创建资料库记录；“另存 PNG”可选择文件位置。按 `Esc` 取消，不产生图片或记录。输出图片包含标注，文字识别在后台处理。

设置中可录制 `Ctrl`、`Alt`、`Shift` 与一个非修饰键的组合，例如 `Alt+A`。应用检查常见系统保留组合和 Windows 全局热键注册；注册失败时保留原快捷键。其他应用内部处理、没有注册为全局热键的组合可能重叠，需要自行选择其他组合。

## 标注与调色盘

工具栏显示当前工具的颜色和大小选项。窄屏可从“工具”菜单选择六种模式。

| 工具 | 选项 |
| --- | --- |
| 画笔、箭头、空心矩形 | 红、蓝、绿、黄、白、黑六色；线宽 1–32 px。 |
| 调色盘 | RGB 滑条、六位 Hex 色值和预览；点击“应用颜色”或按 `Enter`。 |
| 橡皮擦 | 大小 4–80 px；擦掉标注，恢复原截图像素，包括马赛克区域。 |
| 马赛克 | 像素块 6–32 px；块越大，视觉像素化越明显。 |

已有标注保留各自的颜色与大小。无效色值会显示提示。调色盘打开时，`Esc` 先关闭调色盘，再按一次才取消截图。

- `Ctrl+Z` 撤销，`Ctrl+Y` 重做；新标注清空重做历史。
- “清除标注”恢复原图，也可以撤销。
- `B` 画笔、`E` 橡皮、`M` 马赛克、`V` 选区；在色值输入框中这些字母用于输入。

标注颜色、笔宽、橡皮大小、马赛克块大小和资料库缩略图大小会保存到下次启动。马赛克只提供视觉像素化，不用于必须保密的内容。

## 导入、整理与搜索

从托盘打开资料库，将 PNG/JPEG 拖入窗口，或点击“导入”批量选择文件。批量导入逐项显示失败原因。

选中缩略图后可编辑标题、备注、标签和星标。点击“保存修改”或按 `Ctrl+S` 保存。未保存的修改会显示提示；小窗口可点击“详情”或按 `Enter` 打开独立编辑窗，同一条目的主窗字段暂停编辑。关闭编辑窗保留本次会话草稿；退出、备份、迁移或恢复前可选择保存、放弃或取消。

按 `Ctrl+F` 搜索标题、备注、标签和 OCR 文字。标为“正在识别”的图片可以先通过标题和备注找到，识别完成后图片文字也可搜索。搜索是关键词包含匹配，支持“课程”“订单”等短词；引号、百分号和下划线按普通文字处理。

标签用英文或中文逗号分隔。导航按完整标签筛选，可以与关键词组合；标题或 OCR 中出现同词不等于已添加标签。标签两侧空格和英文大小写不影响分类。

删除的图片进入回收站，可以恢复。

## 预览、复制与导出

选中图片后按 `Space` 或双击打开预览。匹配的 OCR 文字行显示橙色边框。

| 操作 | 快捷键 |
| --- | --- |
| 缩放 | `Ctrl` + 滚轮 |
| 平移 | 拖动图片 |
| 复制图片 | `Ctrl+C` |
| 适应窗口 | `Ctrl+0` |
| 实际像素大小 | `Ctrl+1` |
| 关闭预览 | `Esc` |

预览支持长图，适应模式随窗口调整。详情中可复制识别文字、导出图片。

识别失败时图片保留，选择“重新识别”重试。设置中的“检查原图和识别错误”显示原因。原图被外部删除后，缩略图可能仍可见，但预览和导出会报错，需要从备份恢复。另存和导出失败时保留已有目标文件。

## 备份、恢复与退出

在设置中可打开资料文件夹、备份到 ZIP，或恢复到新的资料目录。备份包含图片、文字、分类和回收站记录；请妥善保管备份中的私人资料。

恢复不会覆盖旧库，成功后自动重启。迁移、备份或恢复运行期间，相关数据操作暂停；失败原因显示在设置窗口。

关闭主窗口后应用继续在托盘运行。彻底退出请使用托盘菜单“退出”。卸载保留设置和资料库。

应用和安装包未数字签名，Windows 可能显示发布者未知。测试与限制见[验证记录](validation.md)和[已知限制](limitations.md)。
