## 样式

| 项目 | 规范 |
| --- | --- |
| 字体 | Segoe UI / Microsoft YaHei UI；正文 14 DIP，辅助 12 DIP，标题 20 DIP。 |
| 间距 | 4 / 8 / 12 / 16 / 24 DIP。 |
| 控件 | 输入和按钮约 32 DIP 高，圆角 4 DIP；使用焦点、悬停、选中、禁用状态。 |
| 颜色 | 中性背景、边框和文字；主强调色 `#1769C2`。 |
| 主题 | 资料库支持系统、浅色和深色；截图遮罩采用固定浅色工具栏。 |
| 窗口 | 初始 1200×800 DIP，左栏 176 DIP，详情栏 300 DIP；窄于 1040 DIP 自动收起详情，也可手动折叠。 |
| 图片 | 保持比例，缩略图宽度可调；标题截断后可在详情查看全文。 |
| 语言 | 默认跟随 Windows 界面语言；中文系统用简体中文，其他系统用 English，可手动指定，重启生效。 |

空库提示引导截图或导入，空搜索提示没有匹配结果。OCR 使用“正在识别”“可搜索”“识别失败，可重试”等状态，标题和备注可在识别完成前搜索。

## 应用图标

原创 [SVG](../../assets/screenshotbox.svg) 使用主色 `#1769C2`，结合截图角框与资料卡片。[ICO](../../assets/screenshotbox.ico) 用于 Windows 应用、安装程序和托盘图标。两份资源采用项目的 MIT 许可证。托盘按 Windows 请求的小图标尺寸加载嵌入的 ICO。

SVG 为可编辑源文件。小尺寸图标保留清晰的角框和卡片轮廓，不添加文字。ICO 包含 16、20、24、32、40、48、64、128、256 px 图像，可用 [build-icons.py](../../scripts/build-icons.py) 重新生成，开发依赖列在脚本说明中。正常构建使用仓库内 ICO，应用不增加运行时依赖。

## 截图工具

“保存并复制”将图片加入资料库和剪贴板，“仅复制”“另存 PNG”分别处理。星标独立于保存操作。

工具栏主行保留模式、撤销、重做、保存和取消，只显示当前工具的参数。画笔、箭头和矩形共用六个快捷颜色与 1–32 px 线宽；橡皮大小为 4–80 px，马赛克块大小为 6–32 px。窄布局换行，低于 420 DIP 时将六种模式放入工具菜单。

调色盘提供 RGB 滑条、颜色预览与六位 Hex 输入。颜色和大小只影响后续标注，已有笔画保持其参数。选色本身不进入撤销历史。

每次笔画、形状、马赛克、擦除和清空作为一项历史操作。新编辑清空重做分支；无历史时禁用对应按钮。橡皮重合成原图像素，最终保存与复制使用同一合成结果，OCR 识别该图片。

全局快捷键使用 Ctrl/Alt/Shift 与一个非修饰键。常见系统保留组合提前拒绝，注册失败时保留原组合。

## 资料编辑与预览

主详情和独立编辑窗共享草稿，同一条目只开放一个编辑入口。退出、备份、迁移或恢复前处理未保存修改。设置按快捷键与外观、本地资料、备份恢复、关于分组，操作状态固定显示。

预览支持键盘操作、长图适应、实际像素大小和图片拖动；滚动条保留原行为。OCR 高亮与图片使用同一缩放和平移。

## 资源使用

WPF 负责桌面界面，OCR 使用 CPU 串行队列，限制线程并复用模型；空闲 90 秒后释放模型。缩略图按显示尺寸解码，列表分页。运行时和原生库随包提供，包体与内存记录见[验证记录](validation.md)。布局检查与截图见[界面检查](ui-review.md)。
