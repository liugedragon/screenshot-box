# 本地资料库、搜索与备份

简体中文 · [English](../storage.md)

## 文件组织

资料库独立于安装目录，包含 `library.db`、`images/` 原图和 `thumbnails/` 缩略图。图片以唯一 ID 命名，写入成功后添加数据库记录；原图和缩略图入库后保持不变。回收站采用软删除，保留图片文件。

## 搜索与分类

参数化 SQLite 子串查询搜索标题、备注、标签和 OCR 文字，支持一字、两字中文。引号、百分号和下划线作为普通字符，ASCII 字母不区分大小写。查询扫描记录，不支持模糊、拼音或语义匹配。

结果默认按创建时间倒序，可按最早时间排序并分页。排序在整个匹配集合上进行，再获取一页。“最近保存”先按 UTC 创建时间筛选过去七天，随后排序和分页。

标签列表从全部未删除资料读取。分类匹配完整标签：中英文逗号分隔、Trim、`OrdinalIgnoreCase` 比较；符号作为字面内容。分类与关键词、星标等条件在数据库中相交，再排序与分页。原始标签编辑文本保留。标题或 OCR 中的同词不会自动加入标签。

## OCR 任务

图片先保存，后台再识别。任务取得 generation，结果只写入同代数、未删除且处于 Processing 状态的记录。删除、恢复或新的任务会使过期结果失效。

启动时，中断的 Processing 任务恢复为 Pending 并可重新排队。失败任务保留图片与原因，等待手动重试。详细队列行为见[架构](architecture.md)。

## 备份

SQLite 备份 API 创建一致快照，ZIP 包含快照引用的原图、缩略图和回收站记录。快照之后的修改不进入该包。备份先处理未保存的编辑草稿。

引用图片缺失会导致备份失败，不生成不完整 ZIP，也不覆盖既有目标。备份包含用户资料，保存在用户指定位置。

## 恢复

恢复检查格式版本、SQLite 完整性、文件清单与相对路径，仅安装到新的空目录。校验拒绝路径越界、驱动器和备用数据流路径、重复条目、清单外文件、缺失图片及不支持的版本。恢复不合并或覆盖已有资料库。

初始化恢复的资料库时，建立标准子目录并恢复中断 OCR 任务。应用切换到新库后重启，原库保留。

## 测试

Core 测试覆盖 SQLite 查询与更新、短中文词和符号、排序分页、标签分类、OCR 状态竞态、并发修改期间的备份、恢复字节一致性、缺失文件和危险归档路径。运行方式见[构建](build.md)，版本结果见[验证记录](validation.md)。
