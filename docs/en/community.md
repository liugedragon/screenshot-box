## Short introduction

ScreenshotBox is a Windows screenshot library for the images you want to find again a few days later.

Use a shortcut to select a region, add an arrow or mosaic, then save and copy. Chinese and English OCR runs in the background on your local CPU. Later, search for a word or order number to find the screenshot with matching text lines highlighted on the original.

There is no account or API key. Images and text stay on your computer. You can change the hotkey, install directory, and library location, add tags and notes, restore deleted items, and back up the library to ZIP. An installer and a complete self-contained ZIP are available for Windows 11 x64.

Version 0.1.2 is a prerelease. The UI is primarily Chinese; documentation is in Chinese and English. The installer is about 82 MiB including the runtime and OCR models. Mixed-DPI multiple-monitor use still needs more testing. If you keep screenshots of schedules, orders, or software errors, feedback from using it would help.

## What to include when sharing

Use an actual library image and a capture-tool image with synthetic or permitted redacted content. Explain the use case, link the download, and state the prerelease limits. Do not describe planned features as delivered or programmatic checks as a manual user experience.

For everyday users, focus on saving, finding, and local data. For developers, link the [architecture](architecture.md) for coordinates, literal Chinese search, OCR generations, and restore checks instead of putting every detail in a short post.
