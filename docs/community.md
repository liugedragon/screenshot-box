# 项目介绍与分享准备

简体中文 · [English](en/community.md)

当前已经准备了双语 README、真实界面图、下载入口、问题模板和贡献说明。下面的介绍可自行用于分享；尚未在外部社区发帖，也没有做 Star 数量或增长承诺。

## 中文短介绍

做了一个 Windows 截图资料盒，想解决“截完图，过几天就找不到”的问题。

按快捷键框选，画箭头或马赛克，保存并复制。软件在后台用本地 CPU 识别中文和英文；以后搜“课程”“订单”或某个编号，就能找回截图，在原图看到匹配的文字行。

没有账号和 API 密钥，图片与文字留在本机。快捷键、安装位置和资料保存位置都能改，有标签、备注、回收站及 ZIP 备份。Windows 11 x64 可下载安装包或直接解压运行。

目前是 0.1.2 测试版，界面以中文为主，文档有中英文。安装包约 82 MiB，包含运行时与中文模型；混合 DPI 双屏还需要更多实测。如果你经常保存课件、订单或软件报错图，欢迎试试，也欢迎反馈不顺手的地方。

项目：https://github.com/liugedragon/screenshot-box

下载：https://github.com/liugedragon/screenshot-box/releases/tag/v0.1.2

## 分享时附什么

用一张实际资料库图，再附截图标注图；图片必须是合成或经许可脱敏内容。先让读者知道为什么需要它，再给下载链接，最后说明测试版的限制。不要把未来功能写成现有功能，也不要拿程序测试冒充真人体验。

向普通用户介绍时强调保存、找回和本地数据；向开发者介绍时可以补充坐标、中文字面检索、OCR 任务代数与恢复验证。细节直接链接[架构](architecture.md)，不用塞进每条短帖。

## 发布后的维护

- 在适合分享个人开源工具的版块发一条完整介绍，先阅读当地规则，不重复刷帖。
- 收到反馈后记录复现条件，修复一个问题就说明一个结果。
- 新版本更新截图、下载链接和中英文文档，保持信息一致。
- 想增加下载渠道时，先解决发行验证与维护能力，不写尚不存在的商店或包管理器命令。

README 和 Topics 能帮助发现项目，但不能保证 Star。对项目更有价值的是用户能下载、用起来、遇到问题有人跟进。
