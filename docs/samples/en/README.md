Download the PNG files, then choose **Import** in ScreenshotBox or drop them into the library. Wait for **Searchable**, then try `SB-20260926-001`, `B204`, or `queue`. These queries match image text.

Titles, notes, tags, and stars shown in the gallery are example metadata; importing a PNG does not add that metadata automatically. The [recognition record](../../images/en/sample-ocr.json) contains the text, source-image line boxes, confidence values, and model version from a local CPU run.
