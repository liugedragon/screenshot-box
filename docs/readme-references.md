## 我们的首页规则

- 默认中文，英文是完整的独立页面，不把两种语言逐段交错堆叠。
- 开头讲一个问题：截图留在电脑里，过几天还能通过文字找到。少用“强大”“赋能”“一站式”等空泛修饰。
- 下载、截图和最短操作步骤放前面。界面图使用本项目真实运行结果，演示内容是合成资料。
- 功能、计划和未验证条件分别写清楚。文档英文版不等于应用已有英文界面。
- 徽章只显示可核查的版本、构建和许可证；不堆 Star 历史图，不造下载量、赞助者或用户评价。

## 让需要的人更容易发现

仓库简介和 Topics 采用真实用途词：Windows、screenshot、OCR、image-annotation、local-first。标题和前两段说明“本地中文 OCR 截图资料库”，不把项目包装成通用 AI 平台。

首页只保留一次自然的邀请：“如果它帮你找回了一张截图，可以点个 Star；遇到问题也欢迎提 Issue。”贡献入口同时接受文档、翻译、复现步骤和经脱敏的测试样例，不要求每位参与者都写代码。公开用户资料前必须取得许可。

这些是基于上述官方页面的写作选择，不是上游项目对 ScreenshotBox 的推荐。外部社区推广需要另行选择渠道和准备内容，不自动代发消息。

## 刻意不照搬

ScreenshotBox 目前没有云上传、录屏、插件商店、跨平台发行、应用多语言界面或成熟赞助计划，因此不沿用相关板块。只提供现有 GitHub 下载，未进入的软件商店和包管理器不写安装命令。上游项目的品牌图、功能截图和宣传用语不作为本项目资产。

已准备的双语介绍与分享注意事项见[项目介绍](community.md)。仓库简介、下载入口和相关Topics在本次文档更新中同步调整。
