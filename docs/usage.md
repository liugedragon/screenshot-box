# 使用说明

1. 运行setup.exe可选安装目录；或解压完整发行目录，双击ScreenshotBox.exe。首次启动建立本地资料库。设置的“更改保存位置并迁移资料”可选保存目录；非空目录会建立专用资料库子目录，迁移完成后重启。旧目录保留，不自动删除。
2. 按Ctrl+Alt+S，拖出任意矩形；松开后八点调整，选区内拖动移动。红/蓝细/粗画笔与马赛克可选，Ctrl+Z撤销只撤销标注。
3. Enter或“收藏并复制”保存并复制；“仅复制”不进入资料库；“另存PNG”指定位置；Esc取消不生成图片或资料。
4. 截图后回到原应用，识别不挡住工作。点击托盘打开资料库。“正在识别”的截图标题和备注仍能搜索，但OCR文字尚不可搜索。
5. 选中缩略图后填可选标题、备注或标签，点击“保存资料”。小窗口通过“详情”打开编辑窗口。
6. 搜索包含关键词的标题、备注、标签、OCR原始文字；空格预览，匹配OCR文字的行框以橙色显示。
7. 设置可以录制新的Ctrl/Alt/Shift组合键，Alt+A可用；占用或系统保留快捷键会被拒绝，原快捷键继续有效。
8. 备份必须选一个不存在的新ZIP文件。恢复到新目录后彻底退出软件再启动，使用新目录。
9. 主窗口关闭后仍在托盘等待快捷键。彻底退出请使用托盘右键“退出”。

识别失败：图片仍在资料库，选择后“重新识别”；设置的诊断页给出错误原因。原图被外部删除：缩略图可能仍可浏览，预览与导出会报告失败，请从备份恢复。

马赛克是视觉像素化，不适合不可泄露的敏感文字；此版本不提供安全脱敏保证。发行应用未数字签名，Windows可能显示发布者未知。
